
\section{Supplementary Methods: Parameter dynamics and transforms for calibration}\label{sec:S2}

This supplement expands the calibration machinery summarized in the main-text ``Parameter
estimation and forecasting'' section. It describes the models available for how an unknown
parameter evolves over time, the transforms used to constrain such parameters to valid
ranges, and the composite process \texttt{epymorph} uses for estimating strictly-positive,
mean-reverting quantities such as the transmission rate.

\subsection{Parameter dynamics}

Every parameter designated as unknown is assigned a prior distribution, from which its
initial value is drawn for each stochastic realization, and a \emph{dynamics} model that
governs how that value evolves over the simulated time frame. \texttt{epymorph} provides
three built-in dynamics families, and users may implement their own:

\begin{itemize}
\item
  \textbf{Static.} The parameter has no time dependence; the value drawn from the prior is
  held fixed across the time frame. This is appropriate for quantities assumed constant over
  the analysis window.
\item
  \textbf{Brownian motion.} The parameter follows a random walk with a specified volatility,
  evolving independently at each node. This accommodates gradual, unstructured drift but has
  a variance that grows without bound over time.
\item
  \textbf{Ornstein--Uhlenbeck (OU).} The parameter follows a mean-reverting process
  parameterized by its stationary distribution (a long-run mean, a reversion/damping rate,
  and a stationary standard deviation). Unlike Brownian motion, the OU process has a stable
  equilibrium distribution, so its variance does not grow without bound. In
  \texttt{epymorph}, the OU trajectory is generated from the \emph{exact} solution of the
  process rather than an approximate Euler--Maruyama discretization, which avoids
  discretization bias regardless of step size.
\end{itemize}

Unknown parameters may vary across both time and nodes, so a single dynamics specification
produces a time-by-node trajectory for each realization.

\subsection{Transforms}

A dynamics model evolves a parameter on an unconstrained scale. To map such a parameter onto
a physically valid range, \texttt{epymorph} provides transforms that are composed with the
dynamics, including:

\begin{itemize}
\item
  \textbf{Exponential transform}, which maps an unconstrained value onto the strictly
  positive reals, used, for example, to keep a rate parameter positive.
\item
  \textbf{Shift transform}, which offsets a parameter to enforce a lower or upper bound.
\end{itemize}

\subsection{The Black--Karasinski process for transmission-rate estimation}

Composing an exponential transform with Ornstein--Uhlenbeck dynamics on the log scale yields
a \textbf{Black--Karasinski process} for a rate such as the transmission rate. Under this
construction the rate remains strictly positive while its logarithm reverts toward a
stationary mean. Because the underlying OU process has a stable equilibrium distribution
rather than a variance that grows without bound, the Black--Karasinski process is
particularly well suited to estimating long-run and forecasted transmission dynamics, where
an unbounded random walk would accumulate unrealistic uncertainty~\citep{drennan_estimating_2026}. This makes it a
sensible default for the time-varying transmission rate in calibration and forecasting
experiments.
