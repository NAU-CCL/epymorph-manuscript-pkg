# results

Generated outputs only — figures, the compiled manuscript PDF, lit-search
shortlists, and `manuscript-numbers.tex` (auto-generated LaTeX macros so the
manuscript's inline numbers update whenever the analysis reruns). Nothing here
should be hand-edited; everything should be reproducible by rerunning
`scripts/build.sh`. `checksums.sha256` will record the expected hash of every file
here once the build script exists.
